# 你画我猜 — 项目手册 v1.0

## 基本信息

- **版本**: v8.13（单人模式）/ v6.0（联机模式）
- **类型**: Node.js 全栈应用
- **部署**: GitHub Pages（master 分支 /docs 目录）
- **URL**: https://z15314102792-arch.github.io/draw-and-guess/
- **仓库**: https://github.com/z15314102792-arch/draw-and-guess（公开）
- **入口**: `server.js` 或 `package.json` 中 main 字段
- **分支**: `main`

## 功能概况

- 单人模式：随机词库、Canvas 画布、沉浸模式
- 联机模式：房间制、实时同步、聊天
- 沉浸模式 v8.11+：真正全屏画布 + 吸附式工具栏切换箭头

## 常用操作

```bash
cd C:\draw-and-guess
npm install        # 安装依赖
npm start          # 本地启动
npm audit          # 安全检查
git push origin main  # Railway 自动部署
```
